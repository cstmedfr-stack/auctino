# Vandivo Brand Checklist

## Brand name

Primary brand name:

Vandivo
## Domains

Primary Romania domain:

https://vandivo.ro

Future France domain:

https://vandivo.fr

Protective global domain:

https://vandivo.com

## Product positioning

Vandivo is a modern auction marketplace for trusted online buying and selling.

## Voice

- Clear
- Trustworthy
- Premium
- Direct
- Friendly
- No hype
- No emojis in UI
- No childish language
- No fake urgency

## UI principles

- Trust first
- Price and auction status must be clear
- Seller identity must be visible
- Empty states must guide the user
- Error states must explain what happened
- Mobile must be first-class
- Admin actions must require confirmation
- Destructive actions must never rely on browser confirm

## Naming rules

Use:

- Vandivo
- vandivo.ro
- vandivo.fr
- vandivo.com

Do not use:


- previous project names
- previous locale storage keys
